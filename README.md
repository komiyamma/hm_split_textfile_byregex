# HmSplitTextFileByRegex

![Hidemaru 9.25](https://img.shields.io/badge/Hidemaru-v9.25-6479ff.svg)

秀丸エディタで現在開いているテキストファイルを、指定した「キーワード」や「正規表現」を区切りとして、複数のファイルに分割するマクロです。

## 概要

大量のデータが含まれるログファイルやテキストファイルを、特定の日付やセクションごとなど、意味のある単位で分割したい場合に便利です。

## 特徴

-   **キーワードによる分割**: 指定した単語や文字列を区切りとしてファイルを分割します。
-   **正規表現による分割**: 日付や特定のパターンなど、正規表現を使ってより柔軟な条件でファイルを分割できます。
-   **選べる実行方法**:
    -   **UI版 (`.ui.mac`)**: ダイアログで対話的に分割条件を指定できます。
    -   **設定ファイル版 (`.value.mac`)**: マクロ内の値を直接編集することで、UIなしで繰り返し同じ条件で実行できます。
-   **連番ファイル生成**: 分割後のファイルは `元のファイル名_001.txt` のように自動で連番が振られます。

## 動作環境

-   秀丸エディタ v9.25 以上

## インストール

1.  リリースページからzipファイルをダウンロードします。
2.  zipファイルの中にあるすべてのファイル（`HmSplitTextFileByRegex.***`）を、同じフォルダに展開してください。

## 使い方

**【重要】** 分割後のファイルは、現在開いているファイルと同じフォルダに作成されます。元のファイルを汚さないよう、あらかじめ専用の作業フォルダにファイルをコピーしてから実行することをお勧めします。

### UIで対話的に分割する場合 (`HmSplitTextFileByRegex.ui.mac`)

1.  分割したいテキストファイルを秀丸エディタで開きます。
2.  `HmSplitTextFileByRegex.ui.mac` をマクロとして実行します。
3.  表示されるダイアログに、分割の区切りとしたい「キーワード」または「正規表現」を入力します。
4.  分割方法を選択するボタンをクリックします。
5.  自動でファイルが分割され、同じフォルダに保存されます。

### 設定ファイルで直接実行する場合 (`HmSplitTextFileByRegex.value.mac`)

毎回同じ条件で分割する場合や、他のマクロから呼び出す場合に便利です。

1.  `HmSplitTextFileByRegex.value.mac` をテキストエディタで開きます。
2.  マクロ内の設定値を、ご自身の要件に合わせて編集します。
3.  分割したいファイルを秀丸エディタで開いた状態で、編集した `HmSplitTextFileByRegex.value.mac` を実行します。
